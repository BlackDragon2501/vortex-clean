# Vórtex Clean

Vórtex Clean, de Vortex Company: elimina EXIF, GPS y XMP de tus fotos JPEG, PNG y WebP por lotes, con reporte de lo detectado y descarga en ZIP. Tu privacidad no sale de tu navegador. Gratis, sin anuncios y 100% local.

## Stack

- Next.js 16 + React 19 + Tailwind 4 + TypeScript
- 100% local en el navegador, sin backend y sin variables de entorno

## Desarrollo

```bash
bun install
bun run dev
```

## Producción

```bash
bun run build
```
